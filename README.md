# Cherry Berry

Лендинг инновационного сервиса персонального пошива с 3D-сканированием и AR-примеркой.

## Что внутри

- адаптивный лендинг на React и TypeScript;
- интерактивный конструктор модели, материала и цвета;
- фирменные иллюстрации в `public/`;
- стили и адаптивность в `app/globals.css`;
- основная страница в `app/page.tsx`.

## Локальный запуск

Нужны Node.js 22.13+ и pnpm.

```bash
pnpm install
pnpm dev
```

После запуска откройте адрес, указанный в терминале.

## Сборка

```bash
pnpm build
```

## Загрузка на GitHub

1. Создайте пустой репозиторий на GitHub.
2. Распакуйте архив и загрузите содержимое папки в репозиторий.
3. Не добавляйте `node_modules`, `dist`, `.vinext` и файлы `.env` — они уже указаны в `.gitignore`.

## Структура

```text
app/
  page.tsx       — контент и логика конструктора
  globals.css    — визуальный стиль и адаптивность
  layout.tsx     — метаданные страницы
public/
  hero-cherry.png
  ar-fitting.png
  favicon.svg
```
