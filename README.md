# Cherry Berry

Интерактивный сайт инновационного сервиса персонального пошива с 3D-сканированием и AR-примеркой.

Версия для GitHub Pages находится в корневом `index.html` и не требует сборки.

## Что внутри

- адаптивный лендинг на React и TypeScript;
- интерактивный конструктор модели, материала и цвета;
- настройка длины и посадки, демо-сканирование, расчёт цены;
- сохранение образа в браузере через `localStorage`;
- фирменные иллюстрации в `public/`;
- стили и адаптивность в `app/globals.css`;
- основная страница в `app/page.tsx`.

## Локальный запуск

Нужны Node.js 22.13+ и pnpm.

```bash
pnpm install
pnpm dev
```

После запуска откройте адрес, указанный в терминале.

## Сборка

```bash
pnpm build
```

## Загрузка на GitHub

1. Распакуйте архив `cherryberry-pages-update.zip`.
2. В корне репозитория нажмите **Add file → Upload files**.
3. Перетащите все распакованные файлы и подтвердите замену `index.html`.
4. Нажмите **Commit changes** и дождитесь обновления GitHub Pages.

## Структура

```text
app/
  page.tsx       — контент и логика конструктора
  globals.css    — визуальный стиль и адаптивность
  layout.tsx     — метаданные страницы
public/
  hero-cherry.png
  ar-fitting.png
  favicon.svg
```
